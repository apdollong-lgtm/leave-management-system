FACTORYSTUDIO / INSTALLATION

01 สร้างโปรเจกต์และวางไฟล์

  1. เปิด script.google.com แล้วเลือก New project ตั้งชื่อระบบขององค์กร
  2. แทนเนื้อหา Code.gs และเพิ่มสคริปต์ชื่อ PasswordCrypto ด้วยไฟล์ในแพ็กเกจ
  3. กดเพิ่มไฟล์ HTML ตั้งชื่อ Dashboard แล้ววางเนื้อหา Dashboard.html
  4. เข้า Project Settings เปิด Show appsscript.json manifest file in editor กลับ Editor แล้ววาง manifest จากแพ็กเกจ บันทึกทุกไฟล์

02 ตั้ง รหัสผ่าน ผู้ดูแลและข้อมูลองค์กร

ใน Project Settings → Script Properties เพิ่มชื่อ ADMIN_PASSWORD และ Value เป็น รหัสผ่าน ที่ตั้งเอง รหัสผ่าน 12-128 ตัวอักษรที่ไม่เป็นตัวเลขล้วน กด Save script properties

ไม่มีรหัสผ่านผู้ดูแลเริ่มต้น ใช้รหัสผ่านที่คาดเดายาก และไม่ใส่ รหัสผ่าน ลง GitHub หรือส่งไปพร้อมแพ็กเกจ

ใน Code.gs แก้ค่าต่อไปนี้ให้ตรงกับองค์กร:

ค่าใช้กำหนด
ORG_NAME / ORG_TAGLINEชื่อองค์กรและข้อความบนหน้าเว็บ
DEPARTMENTSตัวเลือกแผนกของผู้ใช้งาน
LEAVE_QUOTAจำนวนวันลาต่อปีของแต่ละประเภท
HOLIDAYSวันหยุดบริษัท เช่น ['2026-12-31']
SPREADSHEET_IDเว้นว่างเพื่อสร้างชีตใหม่อัตโนมัติ

03 รัน setup สร้างฐานข้อมูล

กลับ Editor เลือกฟังก์ชัน setup แล้วกด Run ตรวจสิทธิ์ที่ร้องขอและอนุญาตด้วยบัญชีเจ้าของ ระบบสร้างชีต LeaveRequests และ Users เปิดลิงก์ข้อมูลจาก Execution log

ระบบจำ Spreadsheet ID และ ADMIN_PASSWORD_HASH ใน Script Properties อย่าลบค่าทั้งสองหลังเริ่มใช้งาน เก็บ Google Sheets ให้เข้าถึงเฉพาะผู้รับผิดชอบ

ติดตั้งแยกในบัญชี Google ของแต่ละองค์กร02 / 04
FACTORYSTUDIO / DEPLOY & VERIFY

04 เผยแพร่ Web app

  1. กด Deploy → New deployment เลือกชนิด Web app
  2. ตั้ง Execute as: Me เพื่อให้ระบบใช้สิทธิ์ผู้เผยแพร่เข้าถึงชีต
  3. เลือก Who has access: Anyone หรือขอบเขตที่ผู้ดูแล Google Workspace อนุญาต แล้วกด Deploy
  4. เก็บ Web app URL ที่ลงท้าย /exec สำหรับใช้จริง ส่วน URL /dev ใช้สำหรับผู้แก้ไขโปรเจกต์ทดสอบเท่านั้น

05 เพิ่มผู้ใช้งาน

เปิด Web app URL เข้าด้วยรหัส admin และ รหัสผ่าน ที่ตั้งไว้ เข้าเมนู ตั้งค่า เพิ่มชื่อผู้ใช้ รหัสพนักงาน ชื่อ แผนก สิทธิ์ และรหัสผ่าน 12-128 ตัวอักษร ผู้ใช้เปลี่ยน รหัสผ่าน ของตนเองได้จากเมนูผู้ใช้

สิทธิ์การใช้งาน
employeeยื่นใบลาและดูใบลาของตนเอง
approverดู Dashboard รายงาน ปฏิทิน และอนุมัติใบลา
adminสิทธิ์ผู้อนุมัติ และจัดการผู้ใช้งาน

ทุกสิทธิ์อนุมัติใบลาของตัวเองไม่ได้ บัญชีผู้ดูแลหลัก admin ใช้จัดการระบบและยื่นใบลาไม่ได้ ถ้าผู้ดูแลต้องยื่นใบลา ให้สร้างบัญชีพนักงานของตนเองแยกไว้

06 ทดสอบก่อนส่งมอบ

  1. เข้าสู่ระบบด้วยบัญชีพนักงาน เลือกวันทำงาน กรอกเหตุผล แล้วส่งใบลา จดรหัสคำขอ
  2. ออกจากระบบ แล้วเข้าสู่ระบบด้วยผู้อนุมัติอีกบัญชี ตรวจและอนุมัติคำขอนั้น
  3. กลับเข้าด้วยพนักงาน ตรวจสถานะ ผู้ดูแลตรวจแถวข้อมูลใน Google Sheets ว่าจำนวนวัน ผู้อนุมัติ และสถานะตรงกัน
  4. ทดลองคำขอวันหยุด ใบลาซ้อน และเกินโควตา ระบบต้องปฏิเสธ ทดลองปิดบัญชีแล้วตรวจว่าเข้าต่อไม่ได้
ส่งมอบเมื่อการทดสอบบนเว็บจริงผ่านครบ รวมถึงการบันทึกในชีตและการแยกสิทธิ์
ใช้ข้อมูลทดสอบที่ระบุชัดเจนและไม่เป็นข้อมูล HR จริง03 / 04
FACTORYSTUDIO / OPERATION & UPDATES

กติกาที่ต้องแจ้งผู้ใช้งาน

  • นับวันจันทร์-ศุกร์ ไม่รวมวันหยุดใน HOLIDAYS ครึ่งวันได้เฉพาะวันทำงานวันเดียว ไม่แยกช่วงเช้าและบ่าย
  • โควตาประจำปีรวมคำขอรออนุมัติและอนุมัติแล้ว คำขอไม่อนุมัติคืนโควตา ประเภทที่ไม่ได้กำหนดโควตาไม่จำกัด
  • ช่วงวันลาห้ามซ้อนกับใบลารออนุมัติหรืออนุมัติแล้ว ใบลาข้ามปีต้องแยกคำขอ
  • Session มีอายุสูงสุด 6 ชั่วโมงและอาจหมดก่อนนั้นตาม CacheService เปลี่ยน รหัสผ่าน หรือปิดบัญชีทำให้ Session เดิมใช้ไม่ได้
  • บัญชีจากระบบเดิมต้องให้ผู้ดูแลตั้งรหัสผ่านใหม่ก่อนใช้งาน ประวัติใบลาคงเดิม

อัปเดตโดยคง URL เดิม

  1. สำรอง Google Sheets และจด Spreadsheet ID ไว้ก่อนอัปเดต
  2. วาง Code.gs, PasswordCrypto.gs, Dashboard.html และ manifest เวอร์ชันใหม่ในโปรเจกต์เดิม
  3. เลือก Deploy → Manage deployments → Edit → New version → Deploy ใช้ Web app URL เดิมและทดสอบซ้ำ
ถ้าระบบแจ้งโครงสร้างชีตไม่ตรงกับเวอร์ชันนี้ ให้สำรองชีตเดิมแล้วใช้ชีตใหม่ ห้ามเปลี่ยนหัวตารางเพื่อบังคับให้ผ่าน เพราะตำแหน่งข้อมูลอาจต่างกัน
